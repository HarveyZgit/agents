# eli2x

Explain like I'm in my early twenties and new on the job: literate and capable, but I have no business context and no jargon. Use a self-contained HTML page with big pictures and few words. Define terms the first time they appear. Do not talk down or use kid metaphors.

Write the HTML file to the local working directory and open or preview it locally only. Never upload or publish it to any remote destination — no hosted artifact/sharing services, pastebins, or similar — even if the host provides a built-in publishing capability.
